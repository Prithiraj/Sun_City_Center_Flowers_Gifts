# Sun City Center Flowers & Gifts

Responsive, photo-led static website for Sun City Center Flowers & Gifts in Sun City Center, Florida.

## Live site

https://prithiraj.github.io/Sun_City_Center_Flowers_Gifts/

## Design

The visual direction combines local-florist warmth with an editorial e-commerce layout: cream paper tones, forest green, coral accents, serif display typography, strong mobile quick actions, and real flower photography.

The site keeps ordering on the florist's existing commerce website. Calls-to-action open the live flower catalog while this repository provides a focused landing experience.

## Tech

- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- No build step
- GitHub Pages
- Real floral photography from Unsplash

Three.js was considered but intentionally skipped so real photography stays primary and mobile performance remains strong.

## Local preview

Run a simple static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
